# 背景
在购买到一个投影仪后，期望能有个操作异常简单的电视节目类App，复刻以前电视切节目方式。
第一版`apk`也就诞生了，但是在自己使用的过程中，发现有很多缺点。如：切台等待时间过长、切台失败未处理、切台无明显提示等。

故，考虑以另一种思路来加载视频。同时看到自己上传`gitee`的这个自娱项目有两个`fork`，为防止滥用打来不好影响，后续版本apk和代码考虑对隐私信息处理。

但因受限于本地无测试设备，而投影仪`adb`无法连接，因此不太方便程序正确性验证和问题排查，故考虑写一个工具通过局域网手机和显示本地日志信息。因此需要先做一波基建，命名为`virtual_log`

## 当前版本的思路

1. 继续沿用 `WebView` 封装 CCTV 官方直播页，避免自己维护真实流地址。
2. 将频道目录外置到 `app/src/main/assets/cctv/channels.json`，便于后续增删频道。
3. 主界面改成左侧频道列表、右侧播放区，支持上下左右方向键直接选台。
4. 保留自动加载、自动识别全屏按钮的交互，同时修复切台回退、加载态和失败态问题。
5. 增加“电视直播 / 本地视频”双入口，本地视频通过系统媒体库扫描并使用 Media3 播放。
6. 直播和本地视频都支持双击播放区暂停、再次双击继续播放；遥控器确认键也可切换播放状态。
7. 方案评估见 [`docs/CCTV-app方案评估.md`](docs/CCTV-app方案评估.md)。

## 本地视频

进入“本地视频”后，应用会请求视频读取权限并扫描系统媒体库。扫描结果按最近添加时间排列，支持缩略图、文件夹、时长和文件大小展示，也可以通过“重新扫描”刷新列表。

- Android 13 及以上使用 `READ_MEDIA_VIDEO` 权限。
- Android 12 及以下使用 `READ_EXTERNAL_STORAGE` 权限。
- 遥控器上下/左右键可切换上一条或下一条视频，确认键切换暂停/播放，返回键回到列表。

* `app_v.1.0.apk`：第一版`apk`，基础`webView`封装和响应按键事件，达到基本观影效果；
* 2025年5月24日(`app_v.1.1.apk`)：今天再次安装`Apk`，发现`webView`打开巨慢，需要好几分钟才能播放，故尝试调整了`webView`的加载策略，目前本地验证大约几秒就能播放。

* 当前改造继续：增加左侧频道列表页，遥控器上下左右可直接选台。
* 当前改造继续：增加本地视频扫描与播放列表，使用 Media3 播放，并统一直播和本地视频的双击暂停/继续交互。
